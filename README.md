# 英铁1组批量查重网站

网页前端：https://claudjakstevitaylorm-stack.github.io/yingtie-group1-video-check/
共享API及同版本网站：https://clipguard-team-video.claudjakstevitaylorm.chatgpt.site/

所有同事免登录、首次填写姓名后自动记住。原视频和审核结果公开共享。项目与英铁数据面板独立。

## 当前规则 v3（2026-10-27）

先选分类和具体模板，再上传视频。只与所选模板比对。画面、字幕、花字、BGM任一有效项相似度≤70%即通过；其他项目即使>70%或尚未完成也不拦截。口播不计分、不加载ASR。没有通过项且仍有识别缺项时待复核；全部可比项目>70%且无缺项时不通过。完全相同文件直接判重复。

判定分数是最低有效分项，报告同时保留四项分数、通过项目、缺项状态和模板快照。没有识别出的值为null而非0。双方都确认无某类内容时，该项不适用；一方可靠存在、另一方明确确认没有时，该项相似度为0。无所选模板时不会通过。

字幕与花字每秒整帧OCR，读取英文文字行坐标，行中心位于底部32%区域归入字幕，其余归入花字。位置划分不是语义分类，特殊排版可能需要人工复核。可分别确认无字幕/无花字。无法获取坐标或可靠文字的项目不参与计分。

BGM继续使用与视频同起止的纯音乐片段（3–90秒、≤20 MB、时长误差≤1秒）；未接入自动人声分离。原音频仅在本机处理，上传音乐指纹供后台复算。

特征版本clipguard-3，规则clipguard-3-any。旧报告保留原结论，界面有旧规则标记，需要重新检测获得新结论。旧模板只有合并文字时，字幕/花字不计分，可靠画面和BGM仍可触发通过；需独立文字分项时由原上传者重新上传模板。

## 分类与共享

按截图11类：无人检票、拆票、Avanti、伊丽莎白、列车分厢、欧洲之星、车门关闭、LNER、GWR、豪华卧铺、睡眠列车；旧模板保留“未分类”。需在各分类上传实际参考视频。

D1保存上传、模板和报告；R2保存原片。前端先登记选择再上传原视频，浏览器提取特征，服务器只用登记时保存的模板复算。模板停用、删除或更改分类后待复核，不会回退全库。所有人可读；仅持原浏览器随机凭据的上传者可删除自己的视频、启停及调整自己模板分类。姓名是标签，不是账号认证。

## 主要文件与调试

app.js / index.html / style.css为页面；engine.js判定；recognizer.js和screen-text.js提取/划分文字；bgm.js提取音乐指纹；categories.js声明分类。server/index.js提供API。db/schema.ts和drizzle/为数据库结构及不可改写的迁移。

需要Node.js24及pnpm：

```sh
pnpm install
pnpm run build
pnpm test
node scripts/preview-shared.mjs
```

打开http://127.0.0.1:4173/。本机预览使用临时内存数据，重启清空，不写入正式共享区。tests/browser-qa.html仅由本地预览提供，可生成带字幕与花字的视频验证实际OCR。28项自动化测试覆盖四项OR规则、70%边界、缺项/不适用、后台复算、模板选择、分类、共享、权限和播放。

GitHub Pages从main根目录发布前端；后端由独立Sites项目托管，须同步构建保存发布，仅提交GitHub不会更新API。新增规则与字段都使用既有JSON字段，无需新增数据库迁移。不得将凭据、密钥、姓名记录或真实上传视频提交源码仓库。

## 限制

每批100条、单条100 MiB且90秒以内，每浏览器每小时最多登记200条。识别期间不要关闭页面。首次OCR加载依赖jsDelivr。算法指标不是平台官方判重率，不保证避免限流。每日100条性能及业务误判率尚未实测，浏览器提交特征不具备不可篡改保证。

OCR接口依据：[Tesseract.js v6输出说明](https://github.com/naptha/tesseract.js/issues/993)。
