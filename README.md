OCR接口依据：[Tesseract.js v6输出说明](https://github.com/naptha/tesseract.js/issues/993)。

## 模板直接入库与命名（2026-10-27）

模板上传不做审核，不显示通过/待复核，也不要求确认BGM、字幕、花字。选择分类与视频后，爆款名字按所选分类固定带入，个人名字默认当前姓名、允许修改，最终名称为“爆款名字+个人名字”。个人名字1–30字，禁止加号或换行；服务端统一使用分类名作为新模板的固定爆款名，不信任客户端自由提交的hitName。实际上传者member保持不变。

原片上传完成后先调用finalize（templateOnly:true）直接建立公开模板条目，模板审核状态恒为空，reviewRequired:false。系统随后在当前浏览器自动准备画面/文字参考并通过POST /api/templates/:id/features补充；参考准备不属于审核，失败不删除或拒绝模板，可由原上传者在卡片重试。准备期间请保持页面打开，参考未就绪的模板暂不能用于查重。新模板未提供独立BGM参考时该项不计分，其余有效项仍可按OR规则决定结果。

原上传者可点“改名”，只修改个人名字，固定的爆款名和实际上传者不变；既有检测报告的名称快照不改写。PATCH /api/templates/:id使用personalName参数，尝试修改固定hitName会被拒绝。重新准备特征不会覆盖已修改的个人名字或可靠的已有音乐参考。文件SHA和上传者权限继续校验。每次模板上传使用独立编号；相同SHA可分别入库，原浏览器仅管理自己的条目。

新增template-name.js集中处理命名，engine.js对特征提取排队以避免自动准备与视频检测同时占用OCR。模板准备状态保存在已有feature JSON字段，无需数据库迁移。测试覆盖无需特征即可入库、模板无审核状态、准备失败后保留条目、命名校验、原上传者改名、迟到特征不覆盖个人名字与校验指纹/权限。

命名更正：新增templateNameParts解析既有模板固定部分和个人部分，兼容旧名称；未按新格式命名的旧模板优先使用所属分类作固定爆款名。不批量改写历史模板名称。

## 多人同时上传与审核

每个页面有自己的队列、处理状态和停止操作。共享区刷新不会重置本页队列；同名或相同内容的上传拥有不同UUID与原片路径，不会覆盖他人模板或结果。限额按浏览器凭据分别计算。

POST /api/uploads在登记审核任务时保存所选模板的完整参考快照。后续改名、停用、移动或删除模板不影响该任务；新任务使用登记时的最新版。历史未保存快照的任务沿用旧逻辑，已完成报告不改写。drizzle/0003_fancy_hobgoblin.sql移除模板SHA唯一索引，并新增template_snapshot列，不删除旧数据。浏览器提取仍需保持页面打开，共享服务和网络容量仍为共同资源。

红线提示支持按抽样时间显示约略出现范围，连续命中合并、间隔命中分开，点击时间可跳转播放。旧报告未保存时间信息的，需要重新审核；分数和通过规则不变。

重新审核自动准备缺失模板参考，已有完整抽样证据直接复用。文字证据不再要求覆盖整片40%，改为至少3张有文字的抽样帧，同时保留12个有效词、8个不同词及85%有效词要求。算法evidence-4，旧报告不自动改写；待复核时显示具体卡点。

自动复查：首次识别不足或临时失败，会在同一上传任务中自动加强识别一轮；最终确认前不写入待复核，不重复上传视频或新建记录。旧evidence版待复核记录可使用原模板快照及已保存文字证据自动复算，并保留原判定信息。无法获得可靠证据时不制造通过分数，显示简短原因。

各自电脑优化：模板轻量列表同步，完整特征按版本在当前浏览器缓存（最多50份）；未完成待检测视频及已完成识别步骤保存在浏览器IndexedDB，恢复时先核对云端、跳过已上传部分，避免重复登记、上传和识别。不是字节级或逐帧断点，正在执行的步骤可能重做。空间不足会提示，完成或移除后清理本机视频副本；清理浏览器数据会丢失恢复信息。手动暂停保持暂停；同一浏览器通过Web Locks避免多个标签页重复审核，其他电脑独立运行。

总分展示为平均查重率：四项都有分时等权平均；缺项只平均已有有效分数。列表、报告、CSV一致；通过规则及历史原始判定不变。



品牌拼写自动判断已停用：TrainPal、TRAINPAL及OCR误读变体均不触发RL-17，历史品牌拼写提示按当前规则自动移除；查重分数和其他红线规则不变。

新增内容检查（UK V1.1的选定模块）：明确禁止线下购票话术、竞品贬损、运营商优先推荐仍给红线；staff/hidden/secrets、正常饮酒与宗教旅游不因关键词拦截，TrainPal拼写检查保持关闭。

content-checks.js 保存本次业务活动配置（不是实时价格），检查明确产品句中的价格、折扣、有效期、次数及封顶金额；优惠配置差异和多Code以非阻断提醒展示。Code只提取search/enter/promo code等明确引导后的字母数字码，OCR须在至少两帧重复；不同优惠可使用不同Code，未识别到不判错。时间来自实际抽帧窗口，不声称逐字精确定位。

audio-quality.js 在每位上传者本机读取原视频音轨，检测连续≥3秒近静音、持续满幅采样和明显音量跳变，仅作试听提醒，不推断口播语义、叠轨或BGM盖人声；口播不参与重复率。音轨不可解码会注明未判断，不拦截任务；旧报告不会伪装成已做音频分析，需重新审核后才有新音轨数据。新增检查不使用付费模型、不上传独立原音轨。
