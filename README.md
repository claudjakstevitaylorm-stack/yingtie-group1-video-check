# 英铁1组批量查重网站

浏览器本地运行的英文短视频模板查重工具。当前为开发试用版，尚未开展组员正式使用。

## 本地修改和调试

无需安装 npm 依赖。使用 Python 3 在项目根目录启动：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 http://127.0.0.1:4173/ ，不要双击HTML文件。使用已安装的 Node.js 进行检查：

```sh
npm run check
npm test
```

## 部署到 GitHub Pages

将本目录全部内容上传到 GitHub 仓库根目录（包括 `.nojekyll`），打开仓库 Settings → Pages，Source 选择 Deploy from a branch，Branch 选择 main、目录选择 /(root)，点击 Save。后续提交会触发站点更新。项目使用相对资源路径，可部署在 /仓库名/ 子路径下。

## 修改位置

- index.html：网站名称、页面外壳、首次填写姓名弹窗。
- style.css：样式和响应式布局。
- app.js：姓名记忆、队列、模板、检测记录和CSV导出。
- engine.js：抽帧、指纹、相似度算法和 THRESHOLD。
- recognizer.js：Whisper 英文语音转写和 Tesseract 英文字幕识别。
- 搭建与开发交接报告.md：数据结构、算法、运行限制和排错方法。

## 功能与判定

首次输入姓名，同一浏览器自动记住；模板导入导出；每批最多100条，顺序处理；画面、英文口播、字幕分别比较；取所有启用模板所有维度中的最高分，低于70%且识别完整通过，达到或超过70%不通过，缺项待复核。同文件SHA-256相同为100%。

模板、记录保存在当前浏览器，不自动跨设备共享。视频不上传服务器。姓名只是记录标签，不是身份认证。首次模型加载需要访问 jsDelivr 和 Hugging Face。修改阈值时，还需要同步 app.js 和 style.css 中的70%文字、颜色分支与标尺。

当前不检索平台全网，不保证避免限流；未验证真实业务准确率或100条每日吞吐。公开仓库中的源码可以修改，不能作为不可绕过的审核机制。
